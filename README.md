# Python EDA: Online Retail Sales Analysis

A comprehensive exploratory data analysis of 392,000+ retail transactions using pandas, Python, and data visualization.

## Overview
- **Dataset**: Online Retail II UCI (2010-2011)
- **Rows**: 392,693 (after cleaning)
- **Total Revenue**: £8.8M
- **Unique Customers**: 4,338

## Key Findings

1. **Revenue Trend**: Clear seasonality with peak in November (holiday season)
2. **Geographic Dominance**: United Kingdom represents 89.3% of total revenue
3. **Top Products**: Paper craft items dominate by quantity (80k+ units)
4. **Customer Distribution**: Highly skewed — top customers generate disproportionate revenue
5. **Seasonal Pattern**: Strong spike in Q4, growth through summer months
